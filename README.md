# RBI Credit Control — Methods of Credit Control by the Reserve Bank of India

A complete presentation deck covering the **quantitative (general)** and **qualitative (selective)** instruments that the Reserve Bank of India (RBI) uses to control credit in the economy as part of its monetary policy.

## Contents

| File | Description |
|------|-------------|
| `rbi_credit_control_v6.pptx` | Editable PowerPoint deck (14 slides) |
| `rbi_credit_control_v6.pdf` | Print/share-ready PDF (14 slides) |
| `slides/slide_01.html` … `slides/slide_14.html` | Individual slides as standalone HTML files |

> The HTML slides are the authentic, unmodified originals — the hosting-layer media-guard script injected by the CDN has been stripped, so each file contains only the slide markup and styling.

## Slide overview

1. **Methods of Credit Control by RBI** — title slide; quantitative & qualitative instruments of monetary policy (RBI Headquarters, Mumbai)
2. **Credit Control Methods** — overview: quantitative (general) vs qualitative (selective) methods
3. **Quantitative Methods** — primary objective, key characteristic, and the quantitative instruments
4. **Bank Rate Policy** — how it works; effect of bank rate increases and decreases
5. **Open Market Operations (OMO)** — the two types: OMO purchase (buying) and OMO sale (selling)
6. **Cash Reserve Ratio (CRR)** — how CRR changes affect liquidity and credit
7. **Statutory Liquidity Ratio (SLR)** — SLR mechanics and a CRR vs SLR comparison
8. **Repo Rate** — how it works; hawkish (rate up) and dovish (rate down) effects
9. **Reverse Repo Rate** — how it works, repo vs reverse repo, and key purpose
10. **Qualitative Methods** — primary objective, key characteristic, and the qualitative instruments
11. **Margin Requirements** — effect of higher and lower margin requirements
12. **Credit Rationing** — concept and application
13. **Moral Suasion** — advantages and limitations
14. **Direct Action** — forms of direct action and use as a last-resort tool

## How to use

### Open the HTML slides
Each slide is a self-contained HTML file. Open any of them directly in a browser:

```bash
open slides/slide_01.html      # macOS
xdg-open slides/slide_01.html  # Linux
```

Or serve the folder locally:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000/slides/slide_01.html
```

### Open the deck
- **PPTX** — open `rbi_credit_control_v6.pptx` in PowerPoint, Google Slides, LibreOffice Impress, or Keynote.
- **PDF** — open `rbi_credit_control_v6.pdf` in any PDF reader.
